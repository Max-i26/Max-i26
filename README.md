### 🌟 Featured Projects

#### 1. 🤖 [Friday — No-Code ML Pipeline & AI Visualizer](https://github.com/Max-i26/Friday)
*A complete full-stack web application designed to automate dataset profiling, preprocessing, model selection, and visual analysis without writing code.*
*   **AI Integration:** Leverages **Gemini 3.5 Flash** to automatically analyze dataset columns, infer domain context, and recommend target variables, features, and optimal training models.
*   **ML Pipeline:** Dynamically builds and trains pipelines using **Scikit-learn** (imputation, scaling, label encoding) for both classification and regression algorithms.
*   **Tech Stack:** FastAPI (Python), JavaScript, HTML5, CSS3.

#### 2. 🏫 [NEXLAB — Smart University Resource Booking Platform](https://github.com/sankajithdjinasena/NEXLAB)
*A smart scheduling and resource allocation platform built for Sabaragamuwa University of Sri Lanka.*
*   **Priority Booking Engine:** Enforces automated conflict resolution, priority-based request scoring (urgency, team size, fairness, request age), round-robin time splitting, and waitlist auto-promotion.
*   **Intelligence Dashboard:** Incorporates a rolling 8-week predictive demand forecaster and behavioral tracking flags (e.g. batch-booking and volume anomalies).
*   **Tech Stack:** PHP (PDO), MySQL, HTML5, CSS3, JavaScript, PHPMailer.
*   *Developed for CIPHER 2.0 Case Analysis Competition (Team Leader of Predictra).*

#### 3. 🖥️ [RealityFrame — Browser-Based Computer Vision & AR Hub](https://github.com/Max-i26/Reality-Spec)
*A futuristic, hardware-accelerated computer vision and augmented reality webcam privacy dashboard running entirely in the browser.*
*   **Features:** Real-time gesture control bindings (thumbs up, victory, fist, pinch), interactive 3D holographic wireframes orbiting palms, privacy filters (Portal & Full-Body Invisibility), pixel masks, and canvas recording.
*   **Tech Stack:** React, TypeScript, Vite, Tailwind CSS, Three.js, MediaPipe (Hand/Face Tracking).

#### 4. 🕶️ [StealthDrop — Secure Decoy Messaging Platform](https://github.com/Max-i26/StealthDrop)
*A password-gated secret message delivery service disguised behind a decoy/prank landing page.*
*   **Features:** 15-character unique key per-message encryption, multi-format encoding (binary, octal, decimal, hex), QR delivery, and an automated 3-strike self-destruct mechanism.
*   **Tech Stack:** TypeScript, HTML5, CSS3, JavaScript.

#### 5. 🤰 [Pregnify Web — Maternal Care Portal](https://github.com/sanodyaJinadasa/Pregnify_Web)
*A dedicated web platform designed to assist, educate, and monitor pregnant mothers.*
*   **Tech Stack:** Laravel, Blade (PHP), MySQL, HTML5, CSS3.

#### 6. 🌐 [AUSDAV Connect — Student Association Hub](https://github.com/ausdav-org/ausdav)
*The official student association portal for the All University Students' Development Association Vavuniya.*
*   **Tech Stack:** Vite, React, TypeScript, Tailwind CSS, shadcn-ui, Supabase.

#### 7. 📘 [Pocket Dictionary](https://github.com/Yosa03-dat/iwb25-039-team-syndicate)
*A lightweight synonym and pronunciation lookup API service with a glassmorphism client interface.*
*   **Tech Stack:** Ballerina (Backend API with native CORS and JSON mapping), HTML5, CSS3, JavaScript.

#### 8. 📦 [ClothNet — B2B Online Apparel Platform](https://github.com/Max-i26/ClothNet)
