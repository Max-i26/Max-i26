### 🌟 Featured Projects

#### 🛡️ [NEXLAB — Smart University Resource Booking & Allocation Platform](https://github.com/sankajithdjinasena/NEXLAB)
*A smart PHP/MySQL web application automating resource booking (computer labs, multimedia equipment, meeting rooms) for Sabaragamuwa University.*
* **Features:** AI-powered demand forecasting, priority scoring engine, waitlist auto-promotion, conflict resolution using round-robin splitting, behavioral anomaly tracking (high-volume booking flags), and built-in support chat.
* **Tech:** PHP (PDO), MySQL, HTML5/CSS3/JavaScript, PHPMailer.
* *Developed for the CIPHER 2.0 Case Analysis Competition (Team Leader of Team Predictra).*

#### 🖥️ [RealityFrame — Hardware-Accelerated Computer Vision & AR Hub](https://github.com/Max-i26/Reality-Spec)
*A futuristic browser-based augmented reality webcam privacy dashboard, rebuilt from original Python CLI utilities.*
* **Features:** Real-time gesture control bindings (victory, thumbs up, fist, pinch), portal/full-body invisibility rendering, 3D holographic wireframe overlays using Three.js, face masking, and in-browser canvas media recorder.
* **Tech:** React, TypeScript, Vite, Tailwind CSS, Three.js, MediaPipe Hand/Face Tracking.

#### 🕶️ [StealthDrop — Next-Gen Secure Decoy Messaging](https://github.com/Max-i26/StealthDrop)
*A secure, password-gated secret message delivery network disguised as a decoy/prank landing page.*
* **Features:** Alphanumeric 15-character key-based per-message encryption, multiple encoding algorithms (binary, octal, decimal, hex), QR code redirection, and a 3-strike self-destruct mechanism.
* **Tech:** HTML, CSS, JavaScript, TypeScript (Core logic/encryption).

#### 🌐 [AUSDAV Connect — Student Association Hub](https://github.com/ausdav-org/ausdav)
*The full-stack web presence for the All University Students' Development Association Vavuniya.*
* **Features:** Event scheduling, regional educational resources distribution, and dynamic member portal interfaces.
* **Tech:** Vite, React, TypeScript, Tailwind CSS, shadcn-ui, Supabase.

#### 🤖 [Friday — Automated Machine Learning Pipeline](https://github.com/Max-i26/Friday)
*An automated pipeline to streamline model training, evaluation, and tuning with minimal configuration.*
* **Tech:** JavaScript, Node.js, Python, Scikit-learn.

#### 📘 [Pocket Dictionary](https://github.com/Yosa03-dat/iwb25-039-team-syndicate)
*A lightweight definition, pronunciation, and synonym lookup API service with a sleek glassmorphism UI.*
* **Tech:** Ballerina (Backend API), HTML/CSS/JS (Frontend).

#### 📦 [ClothNet — B2B Online Apparel Platform](https://github.com/Max-i26/ClothNet)
*A dedicated PHP e-commerce ecosystem matching Sri Lankan clothing brands, wholesale merchants, and local retail shops.*
* **Features:** Custom dashboard profiles, secure checkout with invoice generator, file-sharing chat, and real-time alerts.
